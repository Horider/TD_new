# Белый импульс кристаллов

`white-pulse-all-levels.gif` показывает общий цикл: кристаллы плавно белеют и возвращаются к исходному цвету. Отдельные GIF лежат рядом и сохраняют размеры соответствующих башен. Фон GIF тёмный для просмотра; исходные башни и маски остаются прозрачными PNG.

`crystal-mask-level-1.png`, `crystal-mask-level-2.png`, `crystal-mask-level-3.png` — полноразмерные маски в оттенках серого. Белый отмечает видимую часть кристаллов, чёрный — всё остальное. `universal-crystal-mask-atlas.png` содержит те же три маски в одном прозрачном файле; координаты указаны в `universal-crystal-mask-atlas.json`.

Чтобы применить эффект к кристаллам другого цвета при той же компоновке, наложите белый цвет через маску соответствующего уровня. Интенсивность по кадрам: `0, .02, .06, .15, .30, .50, .72, .90, 1, .94, .80, .60, .38, .19, .07, 0`. Добавьте мягкий ореол из размытой маски. Цикл длится около 1,8 секунды и повторяется.

Скрипт `crystal_white_pulse.py` воспроизводит все исходные файлы. Для другого готового изображения башни с тем же расположением кристаллов:

```powershell
python crystal_white_pulse.py --tower path/to/tower.png --mask crystal-mask-level-2.png --output path/to/result.gif
```

Размеры башни и маски должны совпадать. Для другой геометрии кристаллов нужна новая маска.
