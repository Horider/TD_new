# Лесной рубеж

Локальная браузерная tower defense на четырёх акварельных картах. Использует готовые башни из `assets/towers/towers/towers`, их белый импульс из `animation` и все 11 кадров стрелы каждого уровня из `assets/effects/arrow`.

## Запуск

В Windows дважды нажмите `start-game.cmd`. Он запустит локальный сервер и откроет игру в браузере. Используется установленный Node.js или Node.js из локального окружения Codex; установка пакетов не требуется.

Альтернативный запуск из этой папки:

```sh
node server.mjs
```

Адрес: http://127.0.0.1:4173. При таком запуске сервер останавливается сочетанием Ctrl+C. HTML нужно открывать через локальный сервер, поскольку игра использует ES-модули.

## Как играть

- Нажмите на земляную площадку: откроется круглый селектор. Выберите жёлтый кристалл для строительства за 90 золота. Красная, синяя и фиолетовая башни пока закрыты замками.
- Площадки отображаются без плюсика. При наведении или фокусе проигрываются шесть кадров движения один раз, без круга радиуса. Отдельный PNG и кадры находятся в `assets/ui/build-pad`.
- Башни стреляют автоматически. Нажмите на жёлтую башню: по центру башни появятся две отдельные круглые кнопки с промежутком. Слева — удаление с возвратом золота, справа — улучшение. У каждой кнопки своя подпись и цена. Меню закрывается крестиком, Esc или нажатием на свободную часть карты.
- Доступны три уровня: деревянная башня, каменная башня и цитадель. Улучшения стоят 120 и 210 золота. Продажа возвращает 70% вложений.
- Строительство сопровождается пятнадцатью кадрами акварельной пыли с пилой и молотком. Башня проявляется за 1,1 секунды и начинает стрелять после завершения строительства. Пауза останавливает эффект, анимация сохраняет обычную скорость даже при скорости боя 2×.
- Улучшения также сопровождаются универсальным эффектом из пятнадцати кадров: пыль, молоток с зубилом и белый импульс в конце. Прежняя башня плавно сменяется новой за 1,9 секунды. Под башней отображаются оставшееся время и полоска прогресса. Если улучшение выбрано сразу после строительства, эффект начнётся после завершения строительства.
Кадры строительства и улучшения проигрываются один раз строго по порядку, без ускорения, повторов и смешивания кадров.
- Управление закреплено по краям видимой карты: локации, звук и полный экран сверху; перезапуск, пауза, скорость, масштаб и запуск волны снизу. При уменьшении карты кнопки следуют за её границами и остаются внутри игрового поля. На телефоне область нажатия кнопок не меньше 44 px. В общем виде карты свободные края заполняет размытый фон той же локации. Строить и улучшать можно во время боя.
- Начало каждого маршрута отмечено акварельным красным флажком со следами и указателем направления. Знак остаётся на карте во время боя; PNG находится в `assets/ui/enemy-entrance`.
- Масштаб меняется кнопками −/+, колёсиком мыши или жестом двумя пальцами. Карту можно перетаскивать. Кнопка «Вся карта» закрывает селектор и возвращает общий вид. Селектор и кристаллы масштабируются вместе с игрой; прозрачность кольца не затрагивает кристаллы.
- Победите во всех десяти волнах. Враги, дошедшие до выхода, отнимают жизни. На карте поля враги идут по двум дорогам.
- «Локации» переключает карту и начинает новую попытку. Лучшие результаты каждой карты сохраняются в браузере; незавершённая попытка не сохраняется.
- Пробел — пауза, X — скорость 1×/2×, N — следующая волна, B/U — строительство или улучшение выбранной башни, Esc — снять выделение. Звук включается кнопкой в шапке.

## Структура

- `game/maps.js` — координаты дорог и площадок на итоговых иллюстрациях, характеристики башен и врагов.
- `game/engine.js` — независимая от интерфейса симуляция, экономика, волны, урон и снаряды.
- `game/app.js` — Canvas-отрисовка, спрайтовые анимации, интерфейс и локальные рекорды.
- `game/tower-selector.js` — круглые меню строительства, улучшения и удаления, цены и блокировки.
- `game/view.js` — камера, масштаб, перемещение карты и преобразование игровых координат.
- `styles.css` — оформление и адаптация для небольших экранов.
- `game-screen.css` — экранный интерфейс игры и независимая прозрачность кольца селектора.
- `maps/watercolor-v3-clean` — карты без нарисованных площадок; площадки отрисовываются отдельно из PNG в координатах карты.

Враги намеренно нарисованы простыми квадратными человечками. Для замены на спрайты достаточно изменить `drawEnemy` в `game/app.js`.

## Проверка

```sh
node --test tests/*.test.mjs
node tests/balance.mjs
```

`tests/browser.mjs` — отдельная проверка интерфейса в headless Chrome с Playwright: загрузка ассетов, строительство, улучшение, продажа, стрельба, пауза, все карты, перезапуск и узкий экран. Требует запущенный сервер и Playwright (поддерживается библиотека из окружения Codex). Снимки сохраняются в `test-results`.

`node tests/selector-browser.cjs` проверяет круглый селектор в отдельном тестовом браузере: замки, строительство, оба улучшения, нехватку золота, максимальный уровень, удаление и возврат золота, управление клавиатурой и размещение на узком экране. Сам запускает временный сервер на порту 4184 и останавливает его после проверки. Требует Playwright; снимки сохраняются в `test-results`.

Для настройки координат откройте `http://127.0.0.1:4173/?debug=1`: красные линии покажут реальные маршруты врагов. Баланс этого прототипа предназначен для дальнейшего игрового тестирования.
